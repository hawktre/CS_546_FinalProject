# CS 546 Final Project — Hops Disease Spread Analysis

This repository contains the code and data for a CS 546 final project analyzing the spread of powdery mildew disease across hop-growing regions and evaluating fungicide intervention strategies. The analysis uses network analysis, maximum likelihood estimation, and spatial modeling techniques.

## Project Structure

| Folder / File | Description |
|---|---|
| `data/` | Raw input data including disease records, fungicide spray logs, and economic data |
| `notebooks/` | Jupyter notebooks implementing the analysis pipeline |
| `reports/` | Generated outputs including saved model parameters and LaTeX tables |
| `requirements.txt` | Python package dependencies |
| `LICENSE` | MIT License |

## Setup

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```
