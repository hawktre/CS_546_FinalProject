# data/

Raw input data for the hops disease spread analysis. All grower identifiers have been anonymized by the original authors.

## Structure

| Path | Description |
|---|---|
| `raw/data_2017_v2.csv` | Primary dataset containing 2017 disease and spray records |
| `raw/cost/` | Fungicide cost data |
| `raw/cost/pesticide_price.csv` | Pesticide price reference data |
| `raw/cost/powdery_mildew_fungicide_record_database.csv` | Database of fungicide applications for powdery mildew |
| `raw/economics/` | Economic impact data relating disease incidence to yield and revenue |
| `raw/economics/Cone color_vs_Expected Revenue.csv` | Relationship between cone color and expected revenue |
| `raw/economics/Cone incidence_vs_Cone color_and_Yield.csv` | Cone disease incidence vs. color and yield |
| `raw/economics/Cone incidence_vs_Cone  color_vs_Yield_loss.csv` | Cone disease incidence vs. yield loss |
| `raw/economics/Cone incidence_vs_Cone  color_vs_Yield.xlsx` | Full yield data by disease incidence (Excel format) |
| `raw/economics/Leaf incidence_vs_Cone_incidence.csv` | Relationship between leaf and cone disease incidence |
| `raw/economics/Number_of_Leaves_over_Time.xlsx` | Leaf count observations over time (Excel format) |
