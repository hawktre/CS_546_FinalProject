# notebooks/

Jupyter notebooks implementing the analysis pipeline. Run them in order for a full end-to-end analysis.

## Active Notebooks

| Notebook | Description |
|---|---|
| `1-data-preprocessing.ipynb` | Cleans and prepares the raw spray and disease data for analysis |
| `2-mle.ipynb` | Maximum likelihood estimation of disease transmission model parameters |
| `3-get-edgeweights.ipynb` | Computes network edge weights for the spatial disease spread graph |
